
# Application de prise de notes

 Construite avec HTML, CSS et JavaScript, cette application fournit une interface intuitive qui vous permet de créer, afficher et supprimer facilement des notes. Que vous preniez des notes rapides ou organisiez des tâches détaillées, l'application My Notes offre une expérience fluide et simple pour gérer vos notes personnelles sans aucun problème.

## Fonctionnalités clés

 - Ajouter des notes : les utilisateurs peuvent saisir du contenu pour chaque note.

 - Supprimer des notes : supprimez facilement n'importe quelle note en cliquant sur un bouton.

 - Interface intuitive: L'application est conçue pour être facile à naviguer, avec des boutons et des champs de saisie clairement visibles.

 - Thème clair/sombre: Possiblité de changer le thème de la page soit en light mode, soit en dark mode.

# Technos utilisées

 ● **HTML**: La structure et le contenu de l'application, tels que les entrées, les boutons et les éléments d'affichage des notes.

● **CSS**: Styles personnalisés pour améliorer la conception, notamment la mise en page, les couleurs et les effets de survol.

●  **JavaScript**: Gère la logique d'ajout de nouvelles notes, de gestion de la liste de notes et de suppression dynamique de notes.

## Installation du projet

Pour télécharger ce projet depuis GitHub, procédez comme suit :

▪ **Localisez le bouton** *« Code »* : sur la page principale du repository, généralement en haut à droite, recherchez et cliquez sur le bouton vert « Code ».

▪ **Sélectionnez** *« Télécharger ZIP »* : un menu déroulant apparaîtra. Choisissez l'option "Télécharger ZIP". Cela téléchargera une archive compressée (fichier ZIP) de l'intégralité du référentiel sur votre ordinateur.

▪ **Extrayez les fichiers** : Cliquez avec le bouton droit sur le fichier ZIP et sélectionnez « Extraire tout » (ou utilisez un outil d'extraction tiers comme 7-Zip ou WinRAR si vous préférez). Suivez les invites pour extraire les fichiers.

▪ **Accédez au projet** : une fois extrait, vous disposerez d'un dossier contenant tous les fichiers et répertoires du projet.
